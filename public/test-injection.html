Teste de Injeção Web3

📋 Instruções para Testar

  1. Execute npm run build no projeto
  2. Abra chrome://extensions/ no Chrome
  3. Ative o Modo do desenvolvedor (canto superior direito)
  4. Clique em Carregar sem compactação
  5. Selecione a pasta build/ do projeto
  6. Abra este arquivo HTML no navegador
  7. Clique em Detectar Wallets

1️⃣ Detecção de Wallets

Verifica se há wallets injetadas em window.injectedWeb3

2️⃣ Conectar Wallet

Solicita permissão para acessar as contas da wallet
